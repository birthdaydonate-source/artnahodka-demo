# Выбор ПВЗ в основной форме

В GitHub Pages работает выбор реальных пунктов СДЭК на Яндекс.Карте и в списке адресов. Данные получены из API СДЭК 22.09.2026: 9415 пунктов, 5940 населённых пунктов России. Это сохранённый справочник для статического демо, а не запрос к API при каждом открытии формы. Дата данных отображается в окне.

Расчёт стоимости, сроки доставки, вес, габариты, оформление отправлений и передача фотографий в СДЭК отсутствуют. API-запрос читает только справочник ПВЗ. Ключи СДЭК и токены не входят в репозиторий.

## Форма

Город обязателен при выборе СДЭК. Кнопка «Выбрать пункт на карте» открывает окно. Если название неоднозначно, нужно выбрать населённый пункт с регионом. Выбор отметки или адреса подсвечивает пункт; «Выбрать этот пункт» переносит результат в основную форму. Смена города сбрасывает ПВЗ. При недоступности карты остаётся список настоящих адресов. Если справочник не загрузился, показывается ошибка; фиктивных пунктов нет.

Данные формы: `city` и `cdekCity` — город с регионом, `cdekCityCode` — код города СДЭК, `cdekPvzCode` — код пункта, `cdekAddress` — отображаемый адрес. Поля СДЭК выключены при выборе другой доставки. Отправка заявок в исходном демо не подключена и по-прежнему не выполняется.

## Карта

Публичный браузерный ключ Яндекс.Карт находится в `assets/js/config.js`, параметр `cdek.yandexMapsApiKey`. В кабинете Яндекса должен быть подключён JavaScript API и разрешены домены `birthdaydonate-source.github.io`, а при переносе — `artnahodka.ru` и `www.artnahodka.ru`. Секрет API СДЭК в этот файл добавлять нельзя.

Карта и справочник загружаются только после открытия окна. Метки расположены по координатам из API СДЭК; геокодирование пользовательского текста не используется. Крупные города используют группировку меток. Уничтожение карты при закрытии освобождает её обработчики.

## Обновление справочника

Требуется Python 3 и доступ к API СДЭК. Передайте `CDEK_ACCOUNT` и `CDEK_SECRET` через защищённые переменные окружения, затем выполните:

```sh
python3 scripts/update-cdek-data.py
```

Проверьте результат, закоммитьте только обновлённый `assets/data/cdek-offices.json` и опубликуйте. Скрипт не изменяет старый справочник при неуспешной загрузке и не выводит секреты. Автоматическое расписание в этом демо не настроено.

Для основного сайта этот же скрипт можно запускать по расписанию на сервере, обновляя JSON атомарно. Либо `cdek.directoryUrl` можно направить на собственный HTTPS endpoint с тем же форматом JSON. Ключ СДЭК должен оставаться на сервере, endpoint должен разрешать чтение с домена сайта. При оформлении реальной заявки сервер обязан заново проверить, что код ПВЗ действителен и соответствует коду города; скрытые поля браузера не являются доверенными.

Формат: `cities: [[cityCode, cityName, region]]`; `offices: {cityCode: [[pvzCode, address, longitude, latitude, workTime]]}`; `updatedAt` — ISO 8601.

Официальные источники: https://apidoc.cdek.ru/ и https://yandex.ru/dev/maps/ .
