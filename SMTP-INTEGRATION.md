# Подробная форма → SMTP Яндекса

Отправляются большая форма `#detailed-form`, быстрый заказ `#quick-form`
и форма на странице `messenger.html`. Все используют `api/order.php` и
действующие приватные настройки SMTP. Быстрый заказ не требует доставки: нужны
фотография, контакт и согласие. Тема и текст письма различают три формы. Получатель и логин SMTP:
`zakaz@artnahodka.ru`. Письмо содержит контакт, имя, пожелания, размер,
ориентацию, дату, оформление, выбранный пример, доставку, город, код и адрес
ПВЗ СДЭК. Стоимость доставки, вес и габариты не рассчитываются.

## Размещение

GitHub Pages не запускает PHP. На демо форма честно сообщает, что отправки
нет. Для рабочего сайта нужен PHP 8.1+ с OpenSSL, fileinfo, filter, ctype,
доступом к SMTP `smtp.yandex.ru:465` и HTTPS. PHPMailer 7.1.1 включён;
Composer устанавливать не нужно. Проверка сертификата SMTP включена.

1. Загрузите файлы сайта в корень сайта (например `public_html`).
2. Скопируйте `api/order-config.example.php` в `private/order-config.php`
   **рядом с public_html, вне публичного каталога**. Укажите пароль приложения
   в `smtp_password` либо переменной окружения `ORDER_SMTP_PASSWORD`.
   В приватном установочном архиве настройки уже заполнены.
3. Установите права 700 на private и 600 на конфигурацию; владелец — пользователь
   PHP. PHP должен иметь возможность создать `private/order-data`.
   Если каталоги отличаются, задайте абсолютный путь к конфигурации в
   переменной окружения `ORDER_CONFIG`.
4. `public_url` — HTTPS-адрес корня сайта, без завершающего слеша. Если сайт
   размещён в подпапке, добавьте её. `allowed_origins` содержит только origin,
   без пути. Не используйте `*`. Корень домена настроен на `artnahodka.ru`.
5. В настройках почты Яндекса разрешите доступ почтовых клиентов с паролями
   приложений. Проверьте, что пароль создан для почты нужного ящика.
6. Настройте PHP: `upload_max_filesize=30M`, `post_max_size=155M`,
   `max_file_uploads=10`, `max_execution_time=180`, `max_input_time=300`,
   `memory_limit=256M`. На веб-сервере также разрешите тело запроса 155 МБ
   (например `client_max_body_size 155m` для nginx). Лимиты изменяются в панели
   хостинга или php.ini; клиент не может их увеличить.
7. Ежедневный cron: `php /полный/путь/public_html/scripts/cleanup-orders.php`.
   Удаляет фотографии после 7 дней. Настройте квоту/мониторинг приватного
   хранилища; при большом потоке заявок добавьте защиту от ботов на хостинге.

Для отправки именно с GitHub-демо разместите обработчик на PHP-хостинге,
укажите полный HTTPS URL в `orderEndpoint` в `assets/js/config.js`, добавьте
`https://birthdaydonate-source.github.io` в `allowed_origins`.
Размещённый обработчик требует `api/` и `assets/data/cdek-offices.json`.
Браузерный JS никогда не получает SMTP-пароль.

## Фотографии и повторные запросы

До 10 файлов, по 30 МиБ, суммарно 150 МиБ. Сервер проверяет MIME и расширение.
До 18 МиБ суммарно — вложения плюс ссылки; больше — только ссылки.
Случайные ссылки для скачивания действуют 7 дней. Файлы хранятся вне корня
сайта, скачиваются как вложения и не исполняются. Ссылки дают доступ каждому,
кто их получил: не пересылайте письмо посторонним. Согласуйте этот срок
хранения с политикой обработки персональных данных на сайте.

Защита: фиксированный получатель, проверка Origin, ловушка для ботов,
проверка полей и ПВЗ по справочнику, 5 попыток отправки в час с IP, случайный
номер заявки и блокировка повторной отправки. Заголовки forwarded не считаются
доверенными: за reverse proxy настройте реальный IP на уровне веб-сервера.
При неопределённом ответе SMTP повторная отправка блокируется для того же
номера — проверьте почту/журнал сервера. HTTP-успех означает, что SMTP принял
письмо, а не гарантию попадания во входящие. Автоответ покупателю не отправляется.

## Проверка после загрузки

Отправьте согласованную тестовую заявку с фотографией и выбранным ПВЗ.
Проверьте папки Входящие/Спам, Reply-To, все поля, вложение и ссылку на оригинал.
Проверьте крупную заявку (>18 МиБ) и закрытый доступ к private через HTTP.
PHP-исходник в браузере означает неправильную настройку хостинга: отключите
endpoint до исправления. Пароль нельзя размещать в GitHub, JS или HTML.

SMTP: https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others.html
PHPMailer: https://github.com/PHPMailer/PHPMailer/releases/tag/v7.1.1

## Локальная проверка без отправки реальных писем

`python3 tests/smtp-integration.py` (Python 3 и PHP 8.1+; либо задайте
`PHP_BINARY`). Тест поднимает локальный SMTP-приёмник и PHP-сервер на 18765,
проверяет содержимое письма, вложения, ссылки, повторы, валидацию и очистку.
Он не проверяет реальные учётные данные Яндекса и TLS-соединение с Яндексом.
