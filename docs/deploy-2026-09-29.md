# Перенос обновления ArtNahodka

Публикация выполняется после согласования демо. Полный пакет с параметрами FTPS и пошаговой инструкцией для macOS передаётся владельцу отдельно. Параметры доступа не публикуются в репозитории.

`scripts/deploy-release.py` читает `manifest.json` и каталог `payload/` из подготовленного пакета. Без `--apply` выполняется только проверка. Пароль вводится через `getpass` на компьютере владельца, TLS-сертификат проверяется.

Перед записью проверяются контрольные суммы актуальных файлов хостинга и файлов пакета. Любое расхождение с эталоном или уже установленным обновлением останавливает перенос. Старые версии сохраняются локально. Временная загрузка проверяется до переименования; целевой файл повторно сверяется перед заменой.

Откат восстанавливает только существовавшие файлы из конкретной резервной копии, если после установки они не менялись. Новые страницы и изображения остаются на сервере. Посторонние файлы не удаляются.

В пакет входят только публичные страницы, скрипты интерфейса и изображения. API, конфигурация заказов, клиентские загрузки, приватные каталоги и логи не переносятся.

Проверки скрипта выполняются без сети: `python3 tests/deploy-release.py`. Фактическое подключение FTPS и получение событий VK проверяются только при переносе владельцем.
