## 2. Единые подписи под карточками

Статус: реализовано для демо. Подписи под демонстрационными карточками приведены к прежнему формату.

Во всех карточках, где сейчас стоит длинная подпись:

> N изображения · ИИ-пример · вымышленные персонажи · нажмите, чтобы рассмотреть

вернуть прежний формат:

> N изображения · пример стилизации · нажмите, чтобы рассмотреть

Количество изображений подставляется из данных карточки. Использовать тот же формат для следующих демонстрационных карточек. Задача касается подписей под примерами в галерее.
