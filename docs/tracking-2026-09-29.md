# Пиксель VK / Top.Mail.Ru

Счётчик: **3798068**. Исходный код от владельца сохранён в [плане задач](next-tasks-2026-09-29.md).

Общий файл `assets/js/vk-pixel.js` подключается на страницах сайта. Он использует присланную JavaScript-часть счётчика и включает её только на `artnahodka.ru` и `www.artnahodka.ru`. На GitHub Pages, localhost и других адресах запросы к счётчику не отправляются. Повторное подключение файла в пределах одной страницы не создаёт второй просмотр.

Отдельный `noscript`-счётчик из исходного фрагмента не включён: статический HTML не может ограничить его загрузку доменом без JavaScript. Посещения с отключённым JavaScript этот пиксель не учитывает. Это позволяет использовать одинаковые HTML-файлы на демо и основном хостинге.

Действующие блоки Яндекс Метрики №112109971 сохраняются без изменения. Уведомление о cookies приведено в соответствие с подключённой аналитикой и рекламным счётчиком.

До переноса на основной хостинг проверяются загрузка общего файла, ограничение по домену и отсутствие повторной инициализации. Факт поступления событий в кабинет VK проверяется после публикации на основном домене.
